# Базовые персонажи

Четыре оригинальные низкополигональные модели в формате GLB. Геометрия и материалы находятся внутри файлов; внешние текстуры не требуются.

| Файл | Модель | Треугольники |
| --- | --- | ---: |
| `male-body.glb` | Мужское тело в простой одежде, без головы | 3612 |
| `female-body.glb` | Женское тело в простой одежде, без головы | 3612 |
| `male-head.glb` | Мужская голова с короткими волосами | 1824 |
| `female-head.glb` | Женская голова с каре | 2160 |

Оба тела используют одинаковые точки крепления. Обе головы взаимозаменяемы.

- Тело: слот `body`, точка персонажа `body_core`, основной якорь модели `[0, 0.8, 0]`.
- Крепление головы на теле: якорь `head_mount` в `[0, 1.55, 0]`.
- Голова: слот `head`, точка персонажа `head_mount`, основной якорь `neck` в `[0, 0, 0]`.
- Ось Y направлена вверх, персонаж смотрит вдоль +Z. При стандартной установке ступни находятся на верхней поверхности подставки.

В конструкторе выберите модель в разделе «Тело», затем в разделе «Голова». Повторный выбор заменяет деталь в соответствующем слоте. Голова следует за точкой шеи при перемещении и масштабировании тела. Управление загрузками доступно на `/admin`. Это статические модели для прототипа; скелета, анимации и подготовки цельной сетки к печати нет.

Исходный генератор: `scripts/create-starter-characters.mjs`. Команда `node scripts/create-starter-characters.mjs` пересоздаёт файлы.

Загрузка: `node --env-file=.env scripts/publish-starter-characters.mjs`. Опция `--replace-library` удаляет остальные загруженные ассеты после сохранения копий в локальную папку `backups/`.
